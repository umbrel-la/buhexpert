# БухЭксперт AI MVP

Рабочий MVP AI-помощника по демонстрационной базе материалов БухЭксперта. Интерфейс сохраняет трехколоночную компоновку исходного прототипа, а вопросы обрабатываются серверным Route Handler с локальным RAG-lite поиском.

## Технологии

Next.js App Router, React, TypeScript, обычный CSS, серверный OpenAI-compatible API. База данных и UI-библиотеки не требуются.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Production-проверка:

```bash
npm run build
npm start
```

## AI и переменные окружения

Скопируйте `.env.example` в `.env.local` и при необходимости укажите:

```env
AI_API_KEY=
AI_BASE_URL=
AI_MODEL=
NEXT_PUBLIC_YM_COUNTER_ID=
```

`AI_API_KEY` доступен только серверному коду. Пустой `AI_BASE_URL` использует OpenAI API. Без ключа автоматически работает demo mode: локальный поиск остается активным, а ответ строится из найденных материалов.

## Деплой на Vercel

1. Загрузите репозиторий на GitHub.
2. Импортируйте его в Vercel как Next.js-проект.
3. При необходимости добавьте перечисленные переменные окружения.
4. Выполните Deploy. Без переменных окружения демонстрационная версия полностью работоспособна.

## Ограничения MVP

- Материалы и ответы демонстрационные и не являются бухгалтерской консультацией.
- Поиск основан на совпадениях текста, без векторной базы.
- Лимит трех вопросов хранится в cookie и не является production-защитой.
- Форма консультации валидируется, но ничего не отправляет.
- Платежи и личный кабинет не подключены.

Исходный визуальный прототип сохранен в `reference/buhexpert-ai-prototype.html`.
